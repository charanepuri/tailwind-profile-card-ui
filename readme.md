# 🌟 Tailwind Profile Card UI

A modern and responsive Profile Card UI built using **Tailwind CSS**. This project showcases a clean glassmorphism design, gradient backgrounds, hover animations, skill badges, and social media links. It is designed to demonstrate fundamental Tailwind CSS concepts while creating an attractive personal profile component.

---

## ✨ Features

- Responsive Profile Card Design
- Modern Glassmorphism UI
- Beautiful Gradient Background
- Circular Profile Image
- Professional Profile Information
- Skill Tags Section
- Social Media Buttons
- Hover Animations & Smooth Transitions
- Mobile-Friendly Layout
- Built with Utility-First CSS

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/charanepuri/tailwind-profile-card-ui
```

### Navigate to Project Folder

```bash
cd tailwind-profile-card-ui
```

### Install Dependencies

```bash
npm install
```

### Run Tailwind Compiler

```bash
npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
```

### Open Project

Open `index.html` in your browser.
